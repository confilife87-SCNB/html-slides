🎮 Quick, Draw! 소개

Quick, Draw! 구글이 만든 AI 그림 맞추기 게임이에요.
내가 그림을 그리면, AI가 20초 안에 무엇을 그린 건지 맞춰요!
🌐 quickdraw.withgoogle.com
✅ 무료
회원가입 없이 바로 사용
✅ 쉬움
그리기만 하면 돼요

🎮 Quick, Draw! — STEP 1

1
사이트 접속하기 브라우저 주소창에 quickdraw.withgoogle.com 입력 후 Enter
2
시작 버튼 클릭 화면 중앙의 "시작하자!" 버튼을 클릭하세요
3
제시어 확인 화면 위쪽에 그려야 할 단어가 나타나요. 확인하세요!
⏱️ 제시어가 나오면 20초 안에 그려야 해요!

🎮 Quick, Draw! — STEP 2

1
마우스(또는 손가락)로 그리기 검은 화면 위에 제시어를 자유롭게 그려보세요
2
AI가 실시간으로 맞추는 중! 그리는 동안 AI가 "혹시 ○○○인가요?" 라고 말해요
3
6개 제시어 모두 그리기 총 6개의 제시어를 그리면 게임이 끝나요
💡 잘 못 그려도 괜찮아요! AI가 얼마나 맞추는지 확인해 봐요

🎮 Quick, Draw! — STEP 3

1
결과 확인하기 AI가 맞춘 그림과 못 맞춘 그림을 확인해요
2
다른 친구들의 그림 보기 전 세계 사람들이 같은 제시어를 어떻게 그렸는지 볼 수 있어요
💬 이야기 나눠봐요!

"AI가 내 그림을 맞췄나요? 어떤 그림을 잘 맞췄나요?"
"왜 AI는 그림을 알아볼 수 있을까요?"

🎨 AutoDraw 소개

AutoDraw 구글이 만든 AI 그림 도우미예요.
내가 대충 그린 그림을 AI가 예쁜 그림으로 바꿔줘요!
🌐 autodraw.com
✅ 무료
회원가입 없이 바로 사용
🎯 활용
카드, 포스터 만들 때 유용해요

🎨 AutoDraw — STEP 1

1
사이트 접속하기 브라우저 주소창에 autodraw.com 입력 후 Enter
2
"Start Drawing" 클릭 중앙의 버튼을 클릭하면 흰 캔버스가 나타나요
3
왼쪽 도구 확인 연필, 지우개, 색상 도구 등이 왼쪽에 있어요
💡 상단에 AutoDraw 도구(✨ 연필 모양)가 선택되어 있는지 확인하세요

🎨 AutoDraw — STEP 2

1
그리고 싶은 것 자유롭게 그리기 고양이, 집, 나무, 자동차 등 무엇이든 그려보세요
2
상단에 AI 추천 그림 확인 그리는 동안 화면 상단에 AI가 추천하는 예쁜 그림들이 나타나요
🖌️ 잘 못 그려도 돼요! 오히려 대충 그릴수록 AI 추천이 재미있어요 😄

🎨 AutoDraw — STEP 3

1
AI 추천 그림 클릭하기 상단 추천 그림 중 마음에 드는 것을 클릭하면 내 그림이 바뀌어요
2
색상 입히기 왼쪽 색상 도구로 그림에 색을 칠해보세요
3
다운로드 저장 우측 상단 메뉴 → Download 클릭하면 이미지로 저장돼요
💾 저장한 그림은 미리캔버스(2차시)에서 활용할 수 있어요!

🎵 Suno AI 소개

Suno AI 키워드 몇 개만 입력하면 AI가 노래를 만들어줘요.
작곡 실력이 없어도 나만의 노래를 가질 수 있어요!
🌐 suno.com
✅ 무료 플랜
하루 10곡까지 무료 생성 가능
🎯 활용
수업 주제 노래, 자기소개 노래 등
⚠️ 주의 : 구글 또는 마이크로소프트 계정으로 로그인이 필요해요

🎵 Suno AI — STEP 1

1
사이트 접속하기 브라우저 주소창에 suno.com 입력 후 Enter
2
로그인하기 우측 상단 "Sign In" → 구글 계정으로 로그인
3
Create 버튼 찾기 왼쪽 메뉴에서 "Create" 버튼을 클릭하세요
💡 학교 구글 계정이 있다면 바로 사용 가능해요!

🎵 Suno AI — STEP 2

1
Song Description 입력 어떤 노래를 만들지 설명을 입력해요
예) "신나는 봄날 소풍, 밝고 경쾌한 분위기, 한국어"
2
스타일 선택 (선택사항) 팝, 발라드, 힙합 등 원하는 음악 스타일을 입력할 수 있어요
📝 추천 입력 예시
"친구들과 함께하는 즐거운 하루, 밝고 신나는 느낌, 한국어 가사"

🎵 Suno AI — STEP 3

1
Create 버튼 클릭 입력 완료 후 "Create" 버튼을 눌러요. 1~2분 기다리면 노래가 완성돼요!
2
완성된 노래 듣기 재생 버튼(▶)을 눌러서 AI가 만든 노래를 들어보세요
3
공유하기 마음에 들면 링크 복사로 친구들과 공유할 수 있어요
💬 이야기 나눠봐요!

"어떤 노래가 만들어졌나요? 기대했던 것과 같았나요?"

🖼️ 미리캔버스 소개

미리캔버스 한국형 AI 디자인 도구예요.
템플릿을 골라서 내용만 바꾸면 예쁜 카드, 포스터를 만들 수 있어요!
🌐 miricanvas.com
✅ 무료 플랜
기본 템플릿 무료 사용 가능
✅ 한국어 지원
한글 폰트, 한국형 디자인 풍부
⚠️ 주의 : 회원가입이 필요해요 (구글 계정으로 가입 가능)

🖼️ 미리캔버스 — STEP 1

1
사이트 접속하기 브라우저 주소창에 miricanvas.com 입력 후 Enter
2
회원가입 / 로그인 우측 상단 "로그인" → 구글 계정으로 로그인
3
새 디자인 만들기 클릭 메인 화면에서 "새 디자인 만들기" 버튼 클릭
💡 학교 구글 계정이 있으면 별도 가입 없이 바로 로그인 가능해요!

🖼️ 미리캔버스 — STEP 2

1
템플릿 검색하기 검색창에 "자기소개" 또는 "소개 카드" 입력
2
마음에 드는 템플릿 선택 여러 템플릿 중 마음에 드는 디자인을 클릭하세요
3
"이 템플릿 사용하기" 클릭 선택한 템플릿으로 편집 화면이 열려요
💡 무료(🆓) 표시가 있는 템플릿만 골라요!

🖼️ 미리캔버스 — STEP 3

1
텍스트 내용 바꾸기 글자를 클릭하면 내용을 수정할 수 있어요.
이름, 좋아하는 것, 꿈 등을 입력해보세요
2
AI 이미지 기능 사용하기 왼쪽 메뉴 → "AI 이미지" 클릭 → 원하는 그림 설명 입력
3
생성된 이미지 삽입 마음에 드는 AI 이미지를 클릭하면 카드에 바로 들어가요
🎨 AI 이미지 입력 예시
"귀여운 강아지", "봄날 꽃밭", "우주를 나는 고양이"

🖼️ 미리캔버스 — STEP 4

1
전체 디자인 확인하기 완성된 카드를 전체적으로 살펴보고 마음에 안 드는 부분 수정
2
다운로드 저장 우측 상단 "다운로드" 버튼 → PNG 또는 JPG 선택 → 저장
💬 완성 후 이야기 나눠봐요!

"내가 만든 소개 카드를 친구들에게 보여주세요!"
"어떤 부분이 가장 마음에 드나요?"

📖 NotebookLM 소개

NotebookLM 구글이 만든 AI 공부 도우미예요.
자료를 올리면 AI가 읽고 요약해주고, 궁금한 것을 물어볼 수 있어요!
🌐 notebooklm.com
✅ 무료
구글 계정으로 무료 사용
🎧 특별 기능
AI가 팟캐스트처럼 요약을 읽어줘요
⚠️ 주의 : 구글 계정 로그인 필요 / 영어 자료가 더 잘 작동해요

📖 NotebookLM — STEP 1

1
사이트 접속하기 브라우저 주소창에 notebooklm.google.com 입력 후 Enter
2
구글 계정 로그인 학교 구글 계정 또는 개인 구글 계정으로 로그인
3
새 노트북 만들기 "새 노트북" 또는 "New Notebook" 버튼 클릭
💡 노트북 = AI와 함께 공부하는 나만의 공간이에요!

📖 NotebookLM — STEP 2

1
자료 추가하기 왼쪽 "소스 추가" 클릭 → 아래 방법 중 선택
📎 자료 추가 방법
· PDF 파일 업로드
· 웹사이트 URL 붙여넣기
· 직접 텍스트 입력
2
수업 추천 자료 선생님이 미리 준비한 PDF 1장을 업로드해요
(예: 환경, 동물, 우주 등 학생 관심 주제)
💡 자료가 업로드되면 AI가 자동으로 내용을 읽기 시작해요!

📖 NotebookLM — STEP 3

1
AI에게 질문하기 오른쪽 채팅창에 궁금한 것을 입력하고 Enter
💬 질문 예시
· "이 내용을 3줄로 요약해줘"
· "가장 중요한 내용이 뭐야?"
· "초등학생도 알 수 있게 쉽게 설명해줘"
2
AI 답변 확인 AI가 업로드한 자료를 바탕으로 답변해줘요.
틀린 내용이 있는지 함께 확인해봐요

📖 NotebookLM — STEP 4

1
Audio Overview 찾기 오른쪽 패널에서 "Audio Overview" 섹션 찾기
2
"Generate" 클릭 버튼을 누르면 AI 두 명이 대화하듯 자료를 요약해줘요
(1~2분 소요)
3
팟캐스트 듣기 재생 버튼을 눌러 AI가 읽어주는 요약을 들어봐요
💬 이야기 나눠봐요!

"AI가 설명해준 내용 중 가장 흥미로웠던 것은 무엇인가요?"
